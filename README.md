# bash scripts

Набор скриптов, которые могут быть полезны в повседневной работе

## Состав
команда | описание
--------|:--------:
rfv     | поиск по содержимому c открытием в vim, aka ripgrep-fzf-vim
bits    | отображение файла в двоичном виде 0 и 1
color-palete | отображение цветов терминала
psel    | выбор процесса(ов) через fzf с предпросмотром
aptf    | выбор и установка пакета через fzf
preview | предпросмотр - подходит к lf и fzf
